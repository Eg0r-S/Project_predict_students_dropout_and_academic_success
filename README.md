# Project_predict_students_dropout_and_academic_success
Это проект по созданию модели для прогнозирования исключения студентов или их успешного завершения обучения в ВУЗах.

# About dataset
Этот набор данных содержит информацию из высшего учебного заведения о различных переменных, связанных с бакалаврами, включая демографические данные, социально-экономические факторы и академическую успеваемость, для исследования влияния этих факторов на отчисление студентов и академический успех.

    Семейное положение: Семейное положение студента.  (Категориальный)
     Режим подачи: Метод подачи, используемый студентом.  (Категориальный)
    Порядок подачи: Порядок, в котором студент подал заявку.  (Числовой)
     Курс: Курс, который проходит студент.  (Категориальный)
    Дневное/вечернее посещение: Посещает ли студент занятия днем или вечером.  (Категориальный)
     Предыдущая квалификация: Квалификация, полученная студентом до поступления в высшее учебное заведение.  (Категориальный)
     Национальность: Национальность студента.  (Категориальный)
     Квалификация матери: Квалификация матери студента.  (Категорически)
    Квалификация отца: Квалификация отца студента.  (Категориальный)
    Квалификация отца: Квалификация отца студента. (Категориальный)
    Профессия матери: Профессия матери студента.
     Род занятий матери: Род занятий матери студента.  (Категориальный)
    Профессия отца: Профессия отца студента.  (Категориальный)
    Перемещенный: Является ли студент перемещенным лицом.  (Категориальный)
     Образовательные специальные потребности: Есть ли у студента какие-либо специальные образовательные потребности.  (Категориальный)
    Должник: Является ли студент должником.  (Категориальный)
     Актуальность оплаты обучения: Актуальны ли платежи студента за обучение.  (Категорически)
     Пол: Пол студента.  (Категориальный)
    Стипендиат: Является ли студент стипендиатом.  (Категориальный)
    Возраст при поступлении: Возраст студента на момент поступления.  (Числовой)
    Международный: Является ли студент международным студентом.  (Категориальный)
    Учебные единицы 1-й семестр (зачтенные): Количество учебных единиц, зачет которых получил студент в первом семестре.  (Числовое)
    Учебные единицы 1-й семестр (зачисленные): Количество учебных единиц, зачисленных студентом в первый семестр.  (Числовое)
    Учебные единицы 1-й семестр (оценки): Количество учебных единиц, оцененных студентом в первом семестре.  (Числовое)
    Учебные единицы 1-й семестр (утвержденные): Количество учебных единиц, утвержденных студентом в первом семестре.  (Числовой)
